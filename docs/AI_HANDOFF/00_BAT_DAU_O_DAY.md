# Bắt đầu ở đây — Worker V3

Đây là gói bàn giao ngắn cho người/chat tiếp nhận đồ án. Phiên bản chính là **Worker V3 trên nhánh `main`** của [repository](https://github.com/Darrys37/smb-network-monitoring).

Đọc lần lượt:

1. [Trạng thái và cách tiếp tục](01_HIEN_TRANG_VA_CACH_TIEP_TUC.md).
2. [Giới thiệu đồ án](02_GIOI_THIEU_DO_AN.md).
3. [Luồng và mã nguồn](03_LOGIC_DIAGNOSIS_ENGINE.md).

Khi chuyển chat, có thể gửi cả bốn file Markdown trong thư mục này. Manifest ghi nguồn và checksum; tài liệu bàn giao không chứa token, mật khẩu, khóa hoặc database runtime.

Nguồn vận hành hiện hành: [README dự án](https://github.com/Darrys37/smb-network-monitoring/blob/main/README.md), [hướng dẫn V3](https://github.com/Darrys37/smb-network-monitoring/blob/main/system-monitor/README.md), [triển khai](https://github.com/Darrys37/smb-network-monitoring/blob/main/system-monitor/deployment/README.md).

Nhật ký và evidence cũ ở [nhánh lưu trữ](https://github.com/Darrys37/smb-network-monitoring/tree/archive/docs-evidence-before-cleanup-20261105). Không dùng trạng thái VM hoặc số test ở nhật ký cũ làm kết luận về trạng thái live hiện tại.
